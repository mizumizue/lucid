💡 主要な用語の早見表

lucid-memories の想起グラフで使用される主要な用語と概念のクイック解説です。

想起 (Recall / Retrieval) コア動作

AIエージェントが指示を受け取ったとき、関連する過去の決定やルールをデータベースから「思い出す」動作です。

想起イベント (Retrieval Event) 履歴単位

ユーザーがプロンプトを入力した1回のタイミングで裏で走った検索処理の記録（どの質問に対して何がヒットしたか）。

記憶 (Memory / SQLite) データ

設計方針、コーディング規約、メモなど、文章としてSQLiteに永続化された具体的な知識。

Map (知識マップ) グラフ

「AのあとにBを行う」「CはDに依存する」といった知識同士の関係性・手順を管理する構造化ネットワーク。

表示温度 (Temperature) 活性度

記憶の「熱さ」。最近使われたり頻繁に参照されるほど温度が高く（円が大きく暖色に）なります。使われないと冷えます。

memory_score 定着度

記憶の総合重要度スコア。想起された累計回数や鮮度をもとに自動算出され、重要な記憶ほど高くなります。
