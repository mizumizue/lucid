## Content

### Contract

正本ダッシュボードのルート `/guide` において、`GuidePage` コンポーネントを配信する。本コンポーネントは目次ナビゲーション、システム概要、インクリメンタル検索可能な用語辞典、想起グラフの読み解き表、ライフサイクルフロー図、および開閉式 FAQ アコーディオンを提供する。

### Inputs

1. **検索キーワード (`termQuery`)**:
   - 用語辞典セクションのインプット要素に入力される文字列（トリムおよび英小文字正規化して比較）。
2. **ナビゲーション操作**:
   - 各画面からの React Router 内部リンク（`<Link to="/guide">`）。
   - 目次内アンカーリンク（`#about`, `#glossary`, `#screen`, `#flow`, `#faq`）。
3. **FAQ クリックイベント**:
   - 各質問行の押下によるアコーディオン展開ステートのトグル。

### Outputs

1. **DOM / UI 出力**:
   - 画面ヘッダー（タイトル、キッカー、概要、および想起グラフ画面へのクイックリンク）。
   - 目次ナビゲーション（各セクションへのスムーズスクロール導線）。
   - システム概要セクション（存在意義、解決する課題）。
   - 用語辞典カード群（用語名、タグバッジ、要約、詳細説明、具体例、およびキーワード・タグ一致判定によるリアルタイムフィルタ）。
   - 想起グラフ読み解きガイド（左・中・右の3カラム役割表、ノードサイズ、エッジ種別の凡例、ツールバー機能解説）。
   - 会話・記憶連携フロー（1〜4ステップの視覚的プロセスブロック）。
   - FAQ アコーディオン（質問行のクリックによる回答の開閉トグル表示）。
2. **URL / ルーティング**:
   - ブラウザのロケーションパス `/guide` と同期。

### Errors

- 検索結果が 0 件の場合: 「該当する用語が見つかりません」の空状態（Empty state）メッセージと検索リセット手段を表示する。

### Constraints

- 外部 HTML（`guide.html`）へのリンク遷移を行わず、完全なクライアントサイド SPA として動作すること。
- 他画面（Overview, Sessions 等）と共通のデザインシステムトークン（`styles.css`）を再利用し、一貫した外観を維持すること。
- アニメーションは 300ms 以内とし、不要なレイアウトシフトを起こさないこと。
