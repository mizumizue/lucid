## Content

### Contract

正本ダッシュボード（`lucid-memories-dashboard`）における全画面のデザイン、タイポグラフィ、レイアウト階層、マイクロインタラクション、および Sonner トースト通知の統合仕様を規定する。

### Inputs

1. **ユーザーアクション**:
   - サイドバーリンクのクリック遷移
   - 更新ボタン（`Refresh`）およびショートカットキー（`R`）
   - コピーボタン（ID、本文、JSON、プロンプト）
   - 検索・フィルター操作およびリセット
   - タブ切り替え（Memory 画面等）
2. **バックエンド API データ**:
   - `/api/v1/overview`, `/api/v1/sessions`, `/api/v1/jobs`, `/api/v1/memory/*`, `/api/v1/recall-graph`, `/api/v1/activity`, `/api/v1/daily`

### Outputs

1. **画面表示**:
   - 二重タイトルが解消され、ブレッドクラムとタイトルが集約されたグローバルトップバー。
   - SVG アイコンとスムーズなアクティブ状態を持つサイドバー。
   - 等幅数字（`tabular-nums`）とホバーフィードバックを備えたサマリーカード。
   - 行ホバー効果とインラインコピーボタンを備えたデータテーブル。
   - コードブロックとメタデータが整理された詳細ビュー。
2. **Sonner トースト通知**:
   - 画面右下にスタック表示される `richColors` 準拠のフローティング通知。
   - コピー成功/失敗、更新実行中/完了、フィルターリセットなどの状態フィードバック。

### Errors

1. **クリップボード書き込み拒否**:
   - ブラウザ権限エラーまたはフォーカス欠落時、フォールバック（`document.execCommand`）を実行し、それでも失敗した場合は `toast.error` で詳細メッセージを表示する。
2. **API 取得エラー**:
   - リソース読み込み失敗時、空状態（EmptyState）の表示とともにエラーメッセージをユーザーに提示する。

### Constraints

1. **外部依存**:
   - トーストライブラリとして公式の `sonner`（React 19 対応）を使用し、CSS は `sonner/dist/styles.css` を適用する。
2. **パフォーマンス**:
   - UI アニメーションの継続時間は 300ms 以内（標準 160ms）とし、不要なレイアウト再計算を避けるため `transform` と `opacity` のみをアニメーション対象とする。
