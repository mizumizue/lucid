## Content

### Contract

`ActivityPage` コンポーネントは、URL クエリパラメータ（`from`, `to`）と連動する期間フィルターコントロールを `.filter-panel` / `.filter-row` スキーマに基づき提供する。

### Inputs

1. **URL クエリパラメータ**:
   - `from`: 開始日（`YYYY-MM-DD` 形式の文字列、初期値空文字）。
   - `to`: 終了日（`YYYY-MM-DD` 形式の文字列、初期値空文字）。
2. **ユーザー操作**:
   - From 入力欄への日付入力・選択。
   - To 入力欄への日付入力・選択。

### Outputs

1. **DOM / UI 出力**:
   - `<Panel className="filter-panel">` 配下の `<div className="filter-row">` 内に配置された 2 つの `<label>` 要素（`From`, `To`）。
   - それぞれの内部に `<input type="date" />` 要素。
2. **URL クエリの更新**:
   - 入力値変更時に `setValue("from", event.target.value)` および `setValue("to", event.target.value)` が呼び出され、ブラウザ履歴およびリソース取得フック（`events`, `artifacts`）に渡される。

### Errors

- 日付のクリア（空文字入力）: フィルター条件が解除され、全期間のデータがリクエストされること。
- 不正な日付形式: ネイティブの `input[type="date"]` バリデーションに従い、不正入力時は値が空として扱われること。

### Constraints

- `ViewIntro` 直下には `SearchInput` のみを配置し、ヘッダー領域の flexbox 崩れを防止すること。
- スタイル定義は既存の `.filter-panel`、`.filter-row`、`.filter-row label`、`.filter-row input` を再利用し、重複やスタイルの乖離を防止すること。
