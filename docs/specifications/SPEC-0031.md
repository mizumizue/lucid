## Content

### Contract

workspace 種別 persona は、global persona を置換せず、confirmed binding に対して種別テンプレート overlay と workspace overlay を上乗せ合成する。binding が pending または未登録の workspace では global persona のみを注入する。

Agent は workspace 初回接触時に種別を推論し `propose` する。binding の確定と override はユーザー操作（CLI / MCP）のみが行える。

### Inputs

- **Hook `beforeSubmitPrompt`**: `payload.workspace_roots[0]`（正規化済み workspace root）
- **`persona_workspace` MCP / CLI `persona workspace`**:
  - `status`: `workspace`（必須）
  - `infer`: `workspace`（必須）
  - `propose`: `workspace`, `type_id`, `rationale`, `confidence`（0.0–1.0）, `proposed_by`（省略時 `agent`）
  - `confirm`: `workspace`, `type_id`（省略時は pending 提案を確定）
  - `reject`: `workspace`
  - `override`: `workspace`, `type_id`（confirmed binding の種別変更）
  - `overlay_set`: `workspace`, `section_id`, `title`, `content`, `priority`
  - `overlay_remove`: `workspace`, `section_id`
  - `types`: 引数なし（登録済み種別テンプレート一覧）

### Outputs

- **`get_injection(workspace_root)`**（hook 内部）:
  - `content`: `[global persona]` を先頭とし、confirmed 時のみ `[workspace persona: <type_id>]` と `[workspace overlay]` セクションを続ける Markdown 風テキスト
  - `token_estimate`, `token_budget`, `omitted_sections`, `over_budget`, `content_hash`
  - `layers`: `{global, type, workspace}` の各層が注入されたか
  - `binding`: `{status, type_id, ...}` または null
- **`persona_workspace` 各 action**:
  - `ok`: boolean
  - binding / overlay / inference / events フィールド（action 依存）
  - 失敗時 `error` コード（`invalid_type`, `binding_not_found`, `not_pending`, 等）

### Errors

- 未知の `type_id` を propose / confirm / override した場合は `invalid_type` を返し、binding を変更しない。
- pending が存在しない workspace を `confirm` した場合で `type_id` も未指定なら `not_pending`。
- persona ファイルまたは DB 読み込み失敗時、hook は global persona のみ、または bootstrap のみを返し Cursor 本体をブロックしない。

### Constraints

- 合成トークン予算は global persona と同一予算（既定 8,000）を共有する。
- 予算超過時の省略順序: workspace overlay sections → type template sections → global sections は省略しない（global は可能な限り保持）。
- binding 変更と override は `workspace_persona_binding_events` に `before_json` / `after_json` と `created_by` を記録する。
- 種別テンプレート正本は `persona/types/<type_id>.json`。初回セットアップ時に既定テンプレートを生成する。
