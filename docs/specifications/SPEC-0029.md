## Content

### Contract

ダッシュボード API は MCP 利用量をモデル Usage と別オブジェクトとして返し、概要・日次・セッション詳細の各画面がその値を表示する。

### Inputs

- 概要: 追加入力なし
- 日次: 集計日数
- セッション詳細: 会話識別子

### Outputs

- 概要: 状態、呼び出し件数、見積もりトークン合計、ツール別件数とトークン、説明文
- 日次: 各日の MCP 呼び出し件数と見積もりトークン合計
- セッション詳細: 当該会話の MCP 呼び出し一覧（時刻、ツール名、見積もりトークン、生成識別子）
- モデル Usage 集計は従来の入出力トークン・コストのみを含み、MCP 見積もりトークンを含めない

### Errors

- 使用量テーブルが無い、または MCP 種別を区別できない場合: モデル Usage は従来どおり返し、MCP 側は未計測として件数 0 と説明文を返す。
- 対象会話が無い場合: 既存のセッション未検出エラーを返す。

### Constraints

- MCP 利用量とモデル Usage を同一の合計値に混ぜない。
- 記録が 0 件でも画面は空状態として描画し、要求失敗にはしない。
