## Content

### Contract

フロントエンドアプリケーションは、ルートDOM要素の `data-theme` 属性（`dark` または `light`）に基づいてCSSカスタムプロパティを制御し、画面全体の一貫した色彩・タイポグラフィ・シャドウを切り替える。また、Sonnerの `<Toaster />` に同期したテーマと通知設定を渡し、UIイベントに応じたトーストメッセージを提供する。すべてのUI文字列はUTF-8で安全にレンダリングされ、一貫した自然な日本語表現規約に準拠する。

### Inputs

- `ThemeMode`: 利用者の選択設定（`"dark" | "light" | "system"`）。ローカルストレージ（キー: `lucid-theme`）から読み込み、未指定時の初期値は `"dark"` とする。
- `SystemTheme`: `window.matchMedia("(prefers-color-scheme: dark)")` の評価結果（真偽値）。
- UIイベント: リフレッシュ実行、クリップボードへのコピー、フィルターリセット、各種エラー発生。

### Outputs

- DOM属性: `<html data-theme="dark">` または `<html data-theme="light">`。
- Sonner Toaster: `theme` プロパティに解決されたテーマ（`"dark"` または `"light"`）を設定。
- トースト通知メッセージ:
  - リフレッシュ開始: `toast.info("最新データに更新中...")`
  - コピー成功: `toast.success("クリップボードにコピーしました", { description: "..." })`
  - コピー失敗: `toast.error("コピーに失敗しました", { description: "..." })`
  - フィルターリセット: `toast.info("フィルターを初期状態にリセットしました")`
- 日本語化されたUI表示要素: 空状態メッセージ、テーブル見出し、ステータスラベル。

### Errors

- ローカルストレージアクセス不可時（プライベートブラウズ等）: インメモリのデフォルト値（`"dark"`）へフォールバックし、描画を継続する。
- クリップボードAPI拒否時: テキストエリア要素を用いたフォールバック処理を実行し、失敗時は `toast.error` で通知する。

### Constraints

- ダークテーマをデフォルトとして提供しつつ、利用者が明示的にライトテーマまたはOS設定を選択できること。
- `<Toaster />` はルート（`App.tsx`）に1つのみ配置し、ページ単位の重複マウントを行わないこと。
- すべてのCSS変数はセマンティックに整理され、文字色・背景色のコントラスト比がWCAG AA（4.5:1以上）を満たすこと。
