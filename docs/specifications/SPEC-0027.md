## Content

### Contract

ダッシュボード起動サブシステムは、コマンドライン引数およびシェルスクリプトを通じて、`lucid_memories.web.dashboard` への適切な引数伝達とブラウザ自動起動を制御する。`lg` コマンドは `lucid-graph` および `lucid-memories dashboard` のラッパー/ショートカットとして機能し、位置引数 `open` または `--open` フラグの指定により、サーバー待受ポートへのブラウザオープン処理を実行する。フロントエンドは旧単一HTML（組み込みUI）ではなく、ビルド済みReact SPAアセット（`src/lucid_memories/web/frontend/dist`）を提供する。

### Inputs

- コマンドライン引数:
  - `lg [open] [--host HOST] [--port PORT] [--open]`
  - `lucid-graph [open] [--host HOST] [--port PORT] [--open]`
  - `lucid-memories open [--host HOST] [--port PORT]`
  - `lucid-memories dashboard [open] [--host HOST] [--port PORT] [--open]`
- 環境変数:
  - `LUCID_MEMORIES_ROOT`: リポジトリのルートパス（未指定時はスクリプト相対位置または `$HOME/.cursor/lucid-memories` を解決）
  - `LUCID_MEMORIES_DASHBOARD_HOST`: サーバーバインドホスト（デフォルト: `127.0.0.1`）
  - `LUCID_MEMORIES_DASHBOARD_PORT`: サーバーバインドポート（デフォルト: `8765`）
  - `LUCID_MEMORIES_DASHBOARD_FRONTEND_DIST`: フロントエンドビルドアセットディレクトリ

### Outputs

- 標準出力:
  - サーバー待受URL: `lucid-memories dashboard: http://{host}:{port}/`
  - ブラウザ起動ログ / バックエンドアクセスログ
- ブラウザ起動:
  - `open` または `--open` 指定時: 既定のブラウザで `http://{host}:{port}/` を開く（`threading.Timer` または `webbrowser.open` 経由）。

### Errors

- Python未検出時: exit code 1 とエラーメッセージ（`{"ok":false,"error":"python not found"}`）を出力。
- ポート重複（バインド失敗）時: exit code 1 とバインド失敗エラーを出力。
- フロントエンドアセット未存在時: 404 またはビルド催促のプレースホルダー応答（`npm run build` を推奨）。

### Constraints

- `lg open` は旧外部リポジトリ（`Projects/lucid-memories-dashboard`）を起動せず、本リポジトリの統合サーバーを起動すること。
- 旧単一HTML組み込みUI（`dashboard.html`）は呼び出さず、Reactフロントエンドアセットを配信すること。
- Windows環境（CMD/PowerShell）およびBash環境（Git Bash/WSL）の両方で同等のコマンド実行（`.cmd` および拡張子なしシェルスクリプト）が機能すること。
