## Content

### Contract

MCP ツール呼び出しが結果を返す直前に、その応答本文の見積もりトークン数とツール名を使用量イベントとして記録する。記録種別はモデル入出力とは別値とし、会話識別子が無い場合は記録を省略する。

### Inputs

- ツール名（必須）
- ツール引数（会話識別子、生成識別子、ワークスペース、トークン予算を含みうる）
- ツール結果オブジェクト、または呼び出し元へ返す結果本文

### Outputs

- 記録成功時: 記録済みを示す真偽値と記録時刻
- 会話識別子を解決できない場合: 呼び出しは成功のまま、未記録理由を返す

### Errors

- 記録処理の失敗はツール結果の返却を妨げない。ツール応答は従来どおり返す。
- ツール自体の実行エラーでも、エラー結果本文を返す経路では消費量を記録してよい。

### Constraints

- 見積もりトークンは、モデルへ渡る結果本文（JSON テキスト）を対象とする。
- 結果に予算や内部トークン数がある場合は付加情報として保持してよいが、モデル入出力トークン欄へ合算してはならない。
- 記録種別は MCP 呼び出しであることが後から区別できる値とする。
