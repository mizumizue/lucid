## Content

### Contract

`privacy_gate` モジュールおよび Git フックは、ファイルパスおよびステージング差分の個人情報パターンマッチング、ローカル専用リポジトリ判定、Git pre-commit フックインターフェース、および Cursor エージェント向け `shell_permission` インターフェースを提供する。

### Inputs

1. **ファイルパス (`path_str`)**:
   - 検査対象の相対または絶対ファイルパス文字列。
2. **リポジトリルート (`repo_root`)**:
   - 検査対象となる Git リポジトリのルートパス。
3. **コマンド文字列 (`command`)**:
   - エージェントがシェルで実行しようとするコマンド文字列。

### Outputs

1. **パス機密判定 (`check_sensitive_path`)**:
   - `tuple[bool, str]`: 機密該当フラグおよび検出理由（未該当時は `(False, "")`）。
2. **ローカル専用判定 (`is_local_only_repo`)**:
   - `bool`: リモート未設定または明示設定時に `True`、リモート設定時に `False`。
3. **ステージング検査結果 (`check_staged_files`)**:
   - `dict[str, Any]`: `{"ok": bool, "local_only": bool, "staged_count": int, "violations": list[dict]}`。
4. **エージェント実行権限 (`shell_permission`)**:
   - `dict[str, Any]`: 違反検知時は `{"permission": "ask", "user_message": "..."}`。

### Errors

- ステージング領域に機密ファイルが存在する状態で `pre-commit` が実行された場合:
  - 標準エラー出力に違反ファイルと理由を出力し、終了コード `1` でコミットを中止する。

### Constraints

- `.env.example`, `.env.template`, `persona/.gitkeep` などの明示的テンプレート・安全ファイルは除外（Allowlist）対象とすること。
- ローカルのみのリポジトリ（リモートが存在しない、または `lucid.localOnly` が `true`）ではブロックしないこと。
