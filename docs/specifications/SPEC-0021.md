## Content

### Contract

ダッシュボードフロントエンド（`dashboard.html`）は、API（`/api/graph`）から取得した想起グラフデータをもとに、対話的なSVG描画、メトリクスサマリー、インクリメンタル検索、双方向ハイライト、クリップボード連携、およびSonner仕様に準拠したフローティングトースト通知を提供する。

### Inputs

1. **API応答データ**: `/api/graph` の JSON 構造（`nodes`, `edges`, `meta`）。
2. **ユーザー入力**:
   - ツールバー: 会話選択（`#conversation`）、データソース選択（`#source`）、期間指定（`#since`, `#until`）、キーワード検索（`#keyword-search`）、更新ボタン（`#refresh`）、リセットボタン（`#reset-filters`）。
   - グラフ内操作: ノードのクリック/Enter（選択）、背景クリック/ESCキー（選択解除）。
   - 詳細パネル操作: クリップボードコピーボタン（プロンプト、記憶本文、ID等）、会話絞り込みボタン。

### Outputs

1. **画面表示**:
   - 上部メトリクスカード（総想起ログ数、アクティブ会話数、記憶数、Mapノード数）。
   - 3列のSVG関係グラフ（会話、想起イベント、記憶/Map）と選択時の接続ハイライト（直接接続ノード・エッジの強調と非接続要素の半透明化）。
   - ノード詳細パネル（メタデータリスト、本文、プロンプト、順位、コピーボタン）。
2. **トースト通知**:
   - 画面右上または右下にスタック表示されるトースト通知（タイトル、説明文、アイコン、richColors、退去アニメーション）。
3. **クリップボード出力**:
   - 対象テキストのシステムクリップボードへの書き込み。

### Errors

- API取得エラー（HTTP 4xx/5xx または通信失敗）: 画面クラッシュを防止し、エラー内容を赤色のエラートーストとして表示するとともに、ステータス表示をエラー状態へ更新する。
- クリップボードAPI拒否（権限未付与など）: コピー失敗の警告トーストを提示し、コンソールに警告を出力する。
- 該当データ0件時: グラフ領域に視覚的な空状態メッセージを案内表示する。

### Constraints

- 外部CDNや追加の外部ネットワーク依存（npm外部スクリプトの実行時取得等）を行わず、ローカル自己完結型（Zero External Dependency）で動作すること。
- モバイル・デスクトップ双方のビューポート幅に対応すること。
- キーボード操作（Tab, Enter, Space, Escape, /）を阻害しないアクセシビリティを維持すること。
