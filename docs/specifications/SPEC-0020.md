## Content

### Contract

`handle_before_submit_prompt` は、システム定義のブートストラップガイダンステキスト（`[lucid-memories]` セクション）と、`persona.get_injection()` で取得されるユーザー定義ペルソナ（`[global persona]` セクション）を統合し、`additional_context` として返却する。

### Inputs

- `payload`: Cursor フック呼び出しパラメータ辞書（`conversation_id`, `prompt`, `workspace_roots` 等を含む）

### Outputs

- `additional_context`: 文字列。以下の構成を含む：
  - システムブートストラップ指示:
    - 作業開始時の `whoami` および `status` 呼び出し
    - compact 後の `reload`
    - 指示実行時の `search` / `recall` / `remember` / `link` の自動実行（Auto）
    - ユーザー承認を要する操作（`confirm`, `forbid`, `archive`）の制限（Ask）
    - CLI/MCP 経由の操作原則（生 SQL / 生 Cypher の抑止）
  - ユーザー定義ペルソナ（`persona.json` / `user-rules.json` が有効な場合）

### Errors

- ペルソナ読み込み時に例外が発生した場合でも、エラーログを記録した上でシステムブートストラップ指示を正常に返却する。
- 致命的例外が発生した場合は空辞書 `{}` を返却し、Cursor 本体の動作をブロックしない。

### Constraints

- 注入テキストは毎プロンプトでコンテキストに載るため、簡潔かつ過不足のない表現でトークン消費を最小化する。
- ユーザー定義ペルソナとシステム指示は明確に区画を分ける。
