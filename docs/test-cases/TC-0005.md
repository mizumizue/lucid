## Content

### Objective

MCPツールおよびCLIコマンドの呼び出しに対して、権限ゲートが安全な操作を `allow`、破壊的・確定操作を `ask` と正しく判定することを検証する。

### Preconditions

- `core.gate` モジュールがロードされていること。

### Steps

1. `mcp_permission(tool_name="search")` を呼び出す。
2. `mcp_permission(tool_name="remember")` を呼び出す。
3. `mcp_permission(tool_name="confirm")` を呼び出す。
4. `mcp_permission(tool_name="archive")` を呼び出す。
5. `mcp_permission(tool_name="link", tool_input={"confirm": True})` を呼び出す。

### Expected Results

- ステップ1および2（search, remember）は `permission: allow` を返す。
- ステップ3および4（confirm, archive）は `permission: ask` を返す。
- ステップ5（link confirm=True）は確定要求であるため `permission: ask` を返す。

### Evidence

- `src/lucid_memories/core/gate.py` の単体テストまたは実行ログ。
