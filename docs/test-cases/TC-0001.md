## Content

### Objective

知識の登録からキーワード全文検索（FTS5）およびベクトル類似度検索（vsearch）によるヒットまでの動作を内部結合レベルで検証する。

### Preconditions

- SQLiteデータベースが初期化されており、埋め込みモックまたはローカル推論基盤が稼働していること。

### Steps

1. `api.remember` を呼び出し、タイトル「Python async tips」、本文「Use asyncio.gather for concurrent execution」、種別「fact」で知識を登録する。
2. 返却された知識IDが有効であることを確認する。
3. `api.search` をキーワード「asyncio」で実行する。
4. `api.vsearch` をクエリ「how to run concurrent tasks」で実行する。

### Expected Results

- 登録処理が成功し、一意のUUIDが返る。
- キーワード検索結果にステップ1で登録した知識が含まれ、一致度が反映されている。
- ベクトル検索結果にステップ1の知識が含まれ、類似度スコアが `min_score` 以上となっている。

### Evidence

- `tests/test_memory_lifecycle.py` および `tests/test_embeddings.py` の実行パス。
