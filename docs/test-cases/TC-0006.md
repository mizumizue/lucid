## Content

### Objective

`scripts/setup.py` のディレクトリ準備処理において、`blobs` および `logs` ディレクトリが生成されないこと、および既存の空ディレクトリが存在した場合に安全に削除されることを検証する。

### Preconditions

- 一時ディレクトリ上に模擬リポジトリ環境を構築できること。

### Steps

1. 一時ディレクトリ `repo_root` を用意する。
2. `ensure_directories(repo_root)` を実行し、`blobs` および `logs` ディレクトリが作成されていないことを確認する。
3. `repo_root / "blobs"` および `repo_root / "logs"` を空ディレクトリとして手動作成する。
4. 再度 `ensure_directories(repo_root)` を実行する。
5. `blobs` および `logs` ディレクトリが削除されていることを確認する。

### Expected Results

- 初期実行時、`.db` と `persona` は作成されるが、`blobs` と `logs` は作成されない。
- 既存の空 `blobs` と `logs` はステップ4の実行により削除され、存在しなくなる。

### Evidence

- `tests/test_setup.py` の実行パス。
