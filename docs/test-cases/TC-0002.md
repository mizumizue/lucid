## Content

### Objective

会話圧縮前のフックで作成されたスナップショットパッケージが、新セッションから指定トークン予算内で正確に復元できることを検証する。

### Preconditions

- 対象セッションにおいて直近のイベント履歴および参照ファイルが存在すること。

### Steps

1. `hook.handle_pre_compact` を実行してスナップショットパッケージを生成・永続化する。
2. `api.status` を呼び出し、`reload_available` が true であることを確認する。
3. `api.reload_pack` を予算2,000トークン指定で実行する。
4. `api.reload_pack` を予算200トークンの制限値で実行する。

### Expected Results

- スナップショットが `compact_snapshot` 種別として正常に保存される。
- 通常予算（2,000）での復元テキストの見積もりトークン数が2,000以内であり、主要な作業状態が含まれる。
- 制限予算（200）での復元テキストの見積もりトークン数が200以内であり、予算超過なくトリミングされる。

### Evidence

- `tests/test_compact_reload.py` の実行ログ。
