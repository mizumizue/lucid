## Content

### Objective

用語・機能ガイドが React / TypeScript SPA のネイティブ画面（`/guide`）として完全統合され、クライアントサイドでの画面遷移、用語検索フィルタリング、FAQ 開閉、およびバックエンドでの SPA 優先配信が正しく動作することを検証する。

### Preconditions

- `src/lucid_memories/web/frontend/` に必要な依存パッケージが導入されていること。
- フロントエンドテストスイート（Vitest）およびバックエンド単体テスト（unittest）が実行可能であること。

### Steps

1. フロントエンド単体テスト（`guidePage.test.ts`）を実行し、用語フィルタリングおよび FAQ アコーディオンの動作ロジックを検証する。
2. バックエンド統合テスト（`tests/test_dashboard_backend.py`）を実行し、SPA ビルド成果物が存在する場合の `/guide` 配信およびフォールバック配信を検証する。
3. `npm run build` を実行し、TypeScript 型検査およびバンドル生成がエラーなく完了することを確認する。

### Expected Results

- すべてのテスト（Vitest、Python unittest）が正常終了（exit code 0）すること。
- フロントエンドのビルド成果物 `dist/` が正常に出力されること。

### Evidence

Vitest 実行ログ、Python テスト実行ログ、およびビルド出力ログ。
