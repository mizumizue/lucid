## Content

### Objective

React ダッシュボードにおいて、Sonner のトースト通知、メトリクスサマリー、キーワード検索、フィルター、接続ハイライト、およびクリップボードコピー機構が正しく統合されていることを検証する。

### Preconditions

- ダッシュボードのローカルHTTPサーバーが起動可能であること。

### Steps

1. `npm test` と `npm run build` を `src/lucid_memories/web/frontend` で実行する。
2. ビルド成果物を配信する HTTP サーバーから `/` と `/guide` を取得する。
3. `/api/v1/recall-graph` が JSON グラフを返し、React Router の画面遷移と UI 操作をブラウザで確認する。

### Expected Results

- フロントエンドの型検査・テスト・ビルドがすべて成功すること。
- React ダッシュボードとガイドが同じ SPA として配信されること。
