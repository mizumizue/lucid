## Content

### Objective

新規セットアップにおいて `persona` ディレクトリ内に空のルールファイルが生成されること、および既存ファイルが存在する場合は保護されることを検証する。

### Preconditions

一時ディレクトリを用意し、リポジトリルートとして設定する。

### Steps

1. 空の一時リポジトリで `ensure_persona` を実行する。
2. 生成された `user-rules.json` と `persona.json` の内容を検査する。
3. `persona.validate_persona()` を実行して検証する。
4. 既存ファイルにダミーのルールを書き込んだ状態で再度 `ensure_persona` を実行し、内容が保持されることを確認する。

### Expected Results

- 初回実行時: `user-rules.json` の `rules` が `[]`、`persona.json` の `sections` が `[]`、バリデーションが成功すること。
- 2回目実行時: 既存のダミールールが上書きされず維持されること。
