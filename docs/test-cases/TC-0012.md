## Content

### Objective

MCP ツール呼び出しが会話に紐づく消費量として記録され、ダッシュボードのモデル Usage 集計から除外されることを検証する。

### Preconditions

- 一時ホームディレクトリ上にセッションを作成できること。
- ダッシュボード用の読み取り SQLite を構築できること。

### Steps

1. 会話識別子付きで MCP ツールを呼び出し、`usage_events` に `event_type=mcp` の行がツール名と見積もりトークン付きで残ることを確認する。
2. 同じデータベースにモデル Usage 行がある状態で概要 API を読み、入力トークン合計に MCP 分が含まれず、MCP 集計だけが件数とトークンを持つことを確認する。
3. セッション詳細 API でモデル Usage 一覧と MCP 一覧が分かれていることを確認する。
4. 会話識別子を解決できない呼び出しではツール結果は返り、使用量行が増えないことを確認する。

### Expected Results

- MCP 行はモデル入出力トークンへ合算されない。
- 概要・セッション詳細から MCP の件数とトークンを読める。
- 会話識別子が無い呼び出しは失敗しない。

### Evidence

- `tests/test_mcp_usage.py` および `tests/test_dashboard_backend.py` の実行ログ。
