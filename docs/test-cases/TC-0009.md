## Content

### Objective

`lucid-memories-dashboard`（リポジトリ内 `src/lucid_memories/web/frontend/`）における全画面のデザイン刷新、Sonner トースト通知配信、ボタンの押下フィードバック、およびビルド適合性を検証する。

### Preconditions

- Node.js 環境および Python 環境が利用可能であること。
- `src/lucid_memories/web/frontend/` の依存パッケージ（`sonner` を含む）がインストールされていること。

### Steps

1. `src/lucid_memories/web/frontend/` において `npm run typecheck` を実行し、TypeScript のコンパイルエラーがないことを確認する。
2. `npm test` を実行し、既存のフォーマット・レイアウトテストが成功することを確認する。
3. `npm run build` を実行し、Vite による本番バンドルが正常に出力されることを確認する。
4. ブラウザ環境（ポート 8765）において、Overview、Sessions、Memory、Recall graph の各画面を描画し、デザイン要素および Sonner トースト通知のトリガーと表示が正常に行われることを検証する。

### Expected Results

- すべてのコマンド（typecheck, test, build）が exit code 0 で完了すること。
- ブラウザ実機において、ボタンクリックやコピー操作に伴い Sonner トーストが指定位置に描画されること。

### Evidence

`npm run build` およびブラウザ実機検証ログ。
