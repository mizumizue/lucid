## Content

### Objective

個人情報および機密情報を含むファイルのパス検出、安全パス判定、ローカル専用リポジトリ判定、Git ステージング検査、および Cursor エージェントゲートによるコミット遮断が仕様どおり動作することを検証する。

### Preconditions

- Python テスト環境および Git コマンドが実行可能であること。
- `src/lucid_memories/core/privacy_gate.py` および `src/lucid_memories/core/gate.py` が配備されていること。

### Steps

1. `tests/test_privacy_gate.py` を実行する。
2. 機密パス（`persona/*.json`, `.env`, 秘密鍵等）が正しく検出されることを確認する。
3. 安全パス（`.env.example`, `persona/.gitkeep` 等）が誤検知されないことを確認する。
4. 一時 Git リポジトリを作成し、リモートの有無および `lucid.localOnly` 設定によるローカル専用判定の切り替えを検証する。
5. 機密ファイルをステージした状態で `check_staged_files` および `gate.shell_permission("git commit ...")` を実行し、コミット遮断および確認要求（ask）が返されることを確認する。

### Expected Results

- すべてのテストケースが成功（exit code 0）すること。
- 機密ファイルがステージされている場合にコミットが確実に阻止されること。

### Evidence

Python unittest 実行ログ（`tests/test_privacy_gate.py`）。
