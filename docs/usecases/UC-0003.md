## Content

### Goal

会話コンテキスト圧縮（コンパクション）後も、エージェントが直前の作業状態と必要な文脈をトークン予算内で引き継げるようにする。

### Trigger

Cursor IDEがトークン上限に近づき、会話圧縮イベントを発火した。

### Preconditions

- 進行中のエージェントセッションが存在する。
- システムがCursor Hooksと連携している。

### Main Flow

1. Cursor IDEが圧縮直前イベント（pre_compact）を発火する。
2. システムが現セッションの重要知識、タスク状態、参照ファイル群をスナップショットパッケージとして永続化する。
3. 新セッション開始後、エージェントが状態確認を行い、復帰可能スナップショットの存在を検知する。
4. エージェントがトークン予算を指定して復帰（reload）を要求する。
5. システムが予算上限内にトリミング・要約された文脈を返し、エージェントが作業を再開する。

### Alternative Flows

- 復元可能なスナップショットが存在しない場合、システムは空の復帰結果を返す。
- 指定されたトークン予算が極端に小さい場合、システムは最優先のメタデータのみを返す。

### Postconditions

- エージェントが過去の文脈を失わずに作業を継続できる。
