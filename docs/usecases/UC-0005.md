## Content

### Goal

ユーザーがプロンプトを送信するたびに、共通の行動指針（ペルソナ）と直近の重要文脈をトークン予算内でシステムプロンプト先頭に自動注入する。

### Trigger

ユーザーがCursor上でプロンプトを送信した。

### Preconditions

- ペルソナ設定ファイルが存在する。
- Cursor Hooks（before_submit_prompt）が構成されている。

### Main Flow

1. Cursor IDEがプロンプト送信前イベントを発火し、入力プロンプトとセッション情報を渡す。
2. システムがペルソナルールを読み込み、トークン予算内で整形テキストを構築する。
3. システムがプロンプト内容に関連する簡易な文脈ダイジェストを付加する。
4. システムが注入用テキストをCursor IDEに返却する。
5. Cursor IDEがプロンプトの先頭に注入文を合成してLLMへ送信する。

### Alternative Flows

- ペルソナ設定が無効または存在しない場合、システムは注入を行わず元のプロンプトを維持する。
- プロンプトからユーザーの指示傾向の変化を検知した場合、システムはバックグラウンドでペルソナ改定候補を記録する。

### Postconditions

- LLMがユーザー固有の行動方針を遵守した状態で応答を生成する。
