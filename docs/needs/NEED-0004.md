## Content

### Background

lucid-memories の Web ダッシュボード（`/`）は、ローカル HTTP サーバー経由でブラウザ上に提供され、AI エージェントの会話セッション、プロンプト実行時に記録された想起イベント、および参照された記憶（SQLite）やナレッジマップ（Map）の 3 列関係グラフを可視化・探索するインターフェースとして機能している。

### Problem

現状のダッシュボードは基本的なグラフ描画と詳細表示を備えているものの、実務における調査や運用の観点で以下の課題を抱えている。

1. **操作フィードバックの不足**: データ更新、フィルター変更、クリップボードコピーなどの操作時に即座に状況を伝える通知システム（トースト通知）が存在せず、処理完了やエラー発生が把握しにくい。
2. **グラフ探索の視認性不足**: 多数のノードやエッジが表示された際、ノード選択時に関連する接続線や隣接ノードが強調されないため、特定の想起イベントに紐づく会話や記憶の因果関係を視覚的に追跡することが困難である。
3. **検索・絞り込みの柔軟性不足**: フィルターが会話セレクトと日時入力に限定されており、特定のプロンプト内容や記憶タイトル・本文を対象としたインクリメンタル検索機能や、全条件を瞬時に初期化するリセット機能がない。
4. **情報の再利用性（コピー操作）の欠如**: 当時のプロンプト文や記憶本文、セッション ID などを他のプロンプトや検証ツールに転記するためのワンクリックコピー機構がなく、手動選択による操作負荷が高い。
5. **情報集約・デザインの洗練不足**: 上部の想起ログ情報が単一行のテキストのみで表示され、アクティビティ全体の概要（セッション数、想起回数、記憶数など）を直感的に把握できるメトリクス表示や、現代的なUIデザイン（タイポグラフィ、レイアウト、アクセシビリティ）の洗練が不足している。

### Desired Outcome

Sonner の設計思想に基づく洗練されたトースト通知（非同期フィードバック・エラー通知・コピー完了など）の導入、グラフ上の双方向ハイライト、リアルタイムキーワード検索とフィルターリセット、本文や識別子のワンクリックコピー機能、視覚的メトリクスサマリーカード、およびレスポンシブ対応を含むモダンなUIデザイン刷新を行い、直感的かつ快適に想起関係を調査・活用できるダッシュボードが実現されること。
