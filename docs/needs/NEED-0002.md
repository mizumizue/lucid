## Content

### Background

lucid-memories は Cursor の Hook（`beforeSubmitPrompt` 等）を通じてユーザーのプロンプトやコンテキストを受け取り、検索ログ（`retrieval_logs`）やセッション状態として SQLite データベースに記録する。記録されたデータは Web ダッシュボードの検索グラフやリコール履歴として可視化される。

### Problem

Windows 環境において、Cursor のフック実行パイプラインが PowerShell 5.1 経由で一時 JSON ファイルを標準入力へ渡す際、UTF-8 文字列が ANSI（CP932）として誤解釈されること等により、日本語テキストが激しく文字化け（Mojibake）した状態で SQLite に永続化されてしまう。これにより、ダッシュボード上の可視化グラフで日本語ノード名やプロンプト内容が解読不能になり、履歴の振り返りや分析が困難になっている。また、既存データベース内にも過去の文字化けレコードが蓄積している。

### Desired Outcome

既存データベースに蓄積された文字化けテキストが原本の会話ログ等から復元され、ダッシュボードのグラフ上で正しい日本語が表示されること。同時に、今後実行されるフック入力においても文字エンコーディングの不整合を自動検知・修復し、文字化けの発生を恆久的に防止すること。
