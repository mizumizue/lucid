## Content

### Background

lucid-memories の運用ダッシュボードは、Cursor フック経由のモデル入出力トークン（Usage）とペルソナ注入の見積もりトークンをすでに可視化している。エージェントは同じ会話ターンの中で MCP ツールを繰り返し呼び、検索・想起・読み込みの結果をコンテキストへ戻す。

### Problem

モデル側のトークン使用量は見えても、MCP ツールが毎回どれだけの結果をコンテキストへ返したかはダッシュボードから分からない。呼び出し回数、ツール名、見積もりトークン、想起・読み込みの予算消化をターン単位で追いづらく、注入コストの内訳を Usage と並べて判断できない。

### Desired Outcome

各 MCP 呼び出しの消費量（回数・見積もりトークン・ツール内訳）が会話ターンに紐づいて記録され、集計画面とセッション詳細でモデル Usage と区別して確認できるようになること。
