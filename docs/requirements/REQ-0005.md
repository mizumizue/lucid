## Content

### Statement

システムは、通常のインライン表示上限を超える巨大な本文や出力データを、ハッシュによる不変ストレージへ退避し、必要に応じて透過的に参照・取得できる。

### Acceptance Criteria

- AC-001: Given 上限サイズを超える本文を持つ知識を保存するとき When 保存処理が実行される Then 本文データはハッシュ参照として退避され知識本体には識別ハッシュが記録される
- AC-002: Given 退避された本文を持つ知識の全体内容を要求するとき When 取得処理が実行される Then ハッシュから完全な本文データが復元されて返る
