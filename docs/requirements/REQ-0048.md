## Content

### Statement

システムは、種別 binding が confirmed の workspace において、全 workspace 共通の global persona を置き換えず、種別テンプレートおよび workspace 固有 overlay を上乗せ合成し、設定されたトークン予算内でプロンプト送信前に自動注入できる。

### Acceptance Criteria

- AC-001: Given confirmed な種別 binding と定義済み種別テンプレート When プロンプト送信前処理が実行される Then global persona、種別 overlay、workspace overlay（存在する場合）が優先順位付きで合成され、単一の注入文として返されること
- AC-002: Given 合成後の注入文 When トークン予算を評価する Then 予算超過時は低優先度の overlay から省略され、省略対象が識別可能であること
- AC-003: Given 種別 binding が未確定の workspace When プロンプト送信前処理が実行される Then global persona のみが注入され、REQ-0047 AC-004 と整合すること
- AC-004: Given workspace 固有 overlay が未設定 When 合成注入が実行される Then global persona と confirmed 種別テンプレートのみで合成されること
