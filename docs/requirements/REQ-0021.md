## Content

### Statement

プロンプト送信前フック（`beforeSubmitPrompt`）において、エージェントが自発的かつ安全に lucid-memories を操作するためのシステムブートストラップ指示を常時自動注入する。これにより、ユーザー設定ファイル（`user-rules.json`）からシステム運用指示を分離し、純粋な利用者の好み・方針のみを保持できるようにする。

### Acceptance Criteria

- AC-001: Given エージェントがプロンプトを処理するとき When `beforeSubmitPrompt` フックが呼び出される Then 返却されるコンテキストに lucid-memories のシステムブートストラップ指示（whoami/status 呼び出し、compact 後の reload、Auto/Ask ガバナンス、生 SQL/生 Cypher 抑止）が含まれる
- AC-002: Given 利用者が独自の `user-rules.json` を設定しているとき When `beforeSubmitPrompt` フックが呼び出される Then システムブートストラップ指示と利用者のグローバルペルソナの両方が統合されて返却される
- AC-003: Given ペルソナ設定が存在しない、または空であるとき When `beforeSubmitPrompt` フックが呼び出される Then システムブートストラップ指示が単独で確実に返却される
- AC-004: Given 環境セットアップ処理を実行するとき When 初期 `user-rules.json` が生成される Then システム運用指示は含まれず、利用者のコミュニケーション方針等に特化したテンプレートが生成される
