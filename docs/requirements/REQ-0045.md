## Content

### Statement

利用者は運用ダッシュボード上で、MCP 呼び出しの件数と見積もりトークン量を全体集計・日次・セッション詳細から確認でき、モデルの入出力トークン表示と取り違えない。

### Acceptance Criteria

- AC-001: Given MCP 呼び出し記録があるとき When 利用者が概要画面を開く Then 呼び出し件数、見積もりトークン合計、ツール別内訳が表示される。
- AC-002: Given 同一会話にモデル Usage と MCP 呼び出し記録があるとき When 利用者がセッション詳細を開く Then それぞれが別の一覧として表示される。
- AC-003: Given 日次集計を表示するとき When MCP 呼び出し記録がその日にある Then その日の MCP 呼び出し件数と見積もりトークン合計が行に含まれる。
