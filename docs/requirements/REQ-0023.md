## Content

### Statement

フック処理において受け取る標準入力テキストの文字エンコーディング（PowerShell 5.1 経由での ANSI / CP932 誤解釈や多重デコード破損）を自動判別・修復し、正しい UTF-8 日本語文字列として処理およびデータベース永続化を行う。

### Acceptance Criteria

- AC-001: Given PowerShell 5.1 経由で ANSI (CP932) として誤デコードされた文字列が標準入力からフックに渡された場合 When フック処理が入力をパースするとき Then 正しい UTF-8 日本語文字列として自動復元されて処理・永続化されること。
- AC-002: Given 正常な UTF-8 日本語文字列が標準入力からフックに渡された場合 When フック処理が入力をパースするとき Then 文字化けや誤変換を起こすことなく、元の文字列がそのまま保持・永続化されること。
