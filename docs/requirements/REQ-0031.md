## Content

### Statement

利用者が Web ダッシュボード上でデータ更新、検索フィルター変更、クリップボードへのコピー、または API 通信エラーに遭遇した際、画面遷移や割り込みダイアログを伴わずに状況を即座に把握できるよう、Sonner の設計思想に基づくフローティングトースト通知を提供する。

### Acceptance Criteria

- AC-001: Given ダッシュボード画面が表示されている When データ更新の完了、フィルター条件の適用、またはテキストのクリップボードコピーが行われる Then 画面端に処理成功を示すトースト通知がスタック形式で即座に表示されること。
- AC-002: Given API からのエラーレスポンス受信や通信障害が発生した When クライアント処理がエラーを検知する Then エラー内容を明示するエラートースト通知が表示され、画面クラッシュを起こさずに利用者へ状況が伝達されること。
- AC-003: Given トースト通知が表示されている When 一定時間が経過するか、利用者がクローズボタンを押下する Then なめらかな退去アニメーションとともにトースト通知が破棄されること。
