## Content

### Statement

AIエージェントおよび利用者は、非同期で実行されているサブエージェントやシェルコマンド等のタスク状態（保留・実行中・完了・失敗等）を別のセッションから一元的に追跡・確認できる。

### Acceptance Criteria

- AC-001: Given タスクが登録・開始されたとき When タスク状態の更新を要求する Then 状態遷移と実行時刻が記録される
- AC-002: Given 別セッションから実行中タスクの確認を要求したとき When 状態一覧を取得する Then 最新の稼働タスクと進行ステータスが返る
