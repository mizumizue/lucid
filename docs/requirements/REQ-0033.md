## Content

### Statement

過去のフック実行等により SQLite データベース内に蓄積された文字化け履歴レコードに対し、会話原本ログまたはエンコーディング逆変換による一括修復手段を提供し、ダッシュボード等での正常表示を回復する。

### Acceptance Criteria

- AC-001: Given SQLite データベース内に過去の文字化けレコードが蓄積している場合 When データ修復処理を実行するとき Then 会話原本ログとの照合または逆エンコード変換により、正しい日本語文字列へと一括復元されること。
- AC-002: Given 修復済みの SQLite データベースを対象とする場合 When ダッシュボードの検索グラフや履歴一覧を表示するとき Then グラフノードのラベルおよびプロンプトが文字化けなく正常な日本語として描画されること。
