## Content

### Statement

`lucid-memories` のダッシュボード起動コマンド体系を整備し、ターミナルから `lg open`（および `lucid-graph open` / `lucid-memories open`）を実行した際に、外部の旧リポジトリではなく本リポジトリに統合されたダッシュボード（バックエンドHTTPサーバーおよびReactフロントエンド）が起動し、自動的にブラウザでフロントエンドUIが開く機能を提供する。なお、旧単一HTML版（組み込みUI）への逆戻りは行わず、統合済みのReactフロントエンドアセットを配信・起動する。

### Acceptance Criteria

- AC-001: Given 利用者がシェルまたはコマンドプロンプトで `lg open`（または `lucid-graph open`）を実行したとき When コマンドが起動される Then 本リポジトリのダッシュボードサーバー（`lucid_memories.web.dashboard`）が起動し、ブラウザで自動的にフロントエンド画面（`http://127.0.0.1:8765/`）が開くこと。
- AC-002: Given 利用者が `lg` または `lucid-graph` を引数なしで実行したとき When コマンドが起動される Then バックエンドサーバーが起動し、コンソールにアクセスURLが表示されること（オプション引数の指定も透過的に渡されること）。
- AC-003: Given 利用者が `lucid-memories` CLI を利用するとき When `lucid-memories open` または `lucid-memories dashboard open` を実行する Then `--open` フラグ指定時と同様にブラウザを自動オープンしてダッシュボードが立ち上がること。
- AC-004: Given リポジトリ内およびユーザーの実行環境において When スクリプト配置が検証される Then `bin/` 配下に `lg`, `lg.cmd`, `lucid-graph`, `lucid-graph.cmd`, `lucid-memories`, `lucid-memories.cmd` が整備され、`~/bin` と整合していること。
- AC-005: Given ダッシュボード起動時 When 配信されるフロントエンドアセットが参照される Then 削除済みの旧単一HTML（組み込みUI）ではなく、`src/lucid_memories/web/frontend/dist` にビルドされたモダンReactフロントエンドが正本として配信されること。
