## Content

### Statement

リポジトリの Git 管理において、ユーザーの個人情報、秘密鍵、認証情報トークン、環境変数設定ファイル等の機密情報が含まれるファイルを追跡対象外（`.gitignore` 等）とし、かつ pre-commit フックおよびエージェント実行時ガード（hooks）を通じて、これらが誤ってステージ・コミットされることを確実に防止する。ただし、外部に公開されないローカル専用リポジトリは検査対象外とする。

### Acceptance Criteria

- AC-001: Given Git管理されているリポジトリ When ユーザー固有のペルソナ（`persona/*.json`）、環境変数（`.env*`）、秘密鍵（`*.pem`, `*.key` 等）、認証トークン（`*credentials*.json` 等）等の機密ファイルが作成された場合 Then `.gitignore` により自動的に追跡対象外として扱われること。
- AC-002: Given Gitステージング領域に対象となる個人情報・機密ファイルが含まれている場合 When Git コミット（`git commit`）が実行されようとする Then `pre-commit` フックおよびエージェントの実行時フック（`gate.py`）により検知され、コミット処理が中止または確認（ask）されること。
- AC-003: Given リモートが存在しないローカル専用リポジトリまたは明示的にローカル専用フラグが設定されている場合 When コミット検査フックが実行される Then 検査がスキップされ、ローカル作業の自由度が阻害されないこと。
