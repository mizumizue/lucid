## Content

### Statement

リポジトリをオープンソースとして匿名公開するにあたり、コードベース、テストケース、パッケージ構成情報から特定の個人実名やローカル開発環境固有のファイルパスを排除し、汎用的なダミー値またはプロジェクト開発者名に置き換える。

### Acceptance Criteria

- AC-001: Given ゲートパーミッションのテストを実行するとき When `tests/test_auto_pipeline.py` が呼び出される Then 個人のホームディレクトリを含まない汎用的なダミーパス（`C:\workspace\lucid-memories\cli.py`）が検証対象となり、テストが正常に通過する
- AC-002: Given MSYS/Windowsパス正規化のテストを実行するとき When `tests/test_compact_reload.py` が呼び出される Then 個人のホームディレクトリを含まない空白付きの汎用パス（`C:\workspace\Alice Smith`）が検証対象となり、スペースを含むパスの正規化検証が正常に通過する
- AC-003: Given パッケージ構成情報を参照するとき When `pyproject.toml` の `authors` を確認する Then 個人の実名ではなくプロジェクト開発者名（`lucid-memories developers`）が定義されている
- AC-004: Given コードベース全体の走査を行うとき When 個人実名およびローカル固有パスを検索する Then 該当する記述が一切検出されない
