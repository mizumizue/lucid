## Content

### Statement

システムは MCP ツールの各呼び出しについて、会話識別子と可能なら生成識別子へ紐づけ、結果本文の見積もりトークン数とツール名を永続化する。モデルの入出力トークン記録とは混在させない。

### Acceptance Criteria

- AC-001: Given 会話識別子付きの MCP ツール呼び出しが完了したとき When 結果が呼び出し元へ返される Then ツール名と結果本文の見積もりトークン数が、その会話（および指定があれば生成）に紐づいて記録される。
- AC-002: Given モデルの入出力トークン記録と MCP 呼び出し記録が両方あるとき When モデル側の使用量を集計する Then MCP 呼び出しの見積もりトークンはモデル入出力トークンへ加算されない。
- AC-003: Given 会話識別子を解決できない MCP 呼び出しがあるとき When 結果を返す Then 呼び出し自体は失敗せず、消費量だけ記録しない。
