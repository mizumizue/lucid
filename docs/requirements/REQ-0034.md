## Content

### Statement

正本ダッシュボード（`lucid-memories-dashboard`）の全ビューにおいて、Sonner トースト通知機構を活用し、データ更新、クリップボードコピー、フィルター操作、タブ切り替え、およびエラー発生時に、視覚的・非同期に状態を知らせるフィードバック機構を提供する。

### Acceptance Criteria

- AC-001: Given ダッシュボードの任意の画面において When 手動更新ボタンまたはショートカットキー（R）を押下するとき Then 最新データ取得の進行および完了が適切な Sonner トースト（情報／成功）で通知されること。
- AC-002: Given 一覧または詳細画面で ID、テキスト、プロンプト、または JSON のコピーボタンをクリックするとき Then 成功または失敗が description つきの Sonner トースト（richColors 準拠）で即時表示されること。
- AC-003: Given トースト通知が表示された場合 When ユーザーがマウスホバーするとき Then 自動消去タイマーが一時停止し、ホバー解除後に正常に消去されること。
