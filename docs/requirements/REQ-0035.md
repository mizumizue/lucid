## Content

### Statement

正本ダッシュボードのサイドバーナビゲーションに洗練された SVG アイコンとアクティブ・ホバー効果を適用し、グローバルトップバーとページ内ヘッダーで重複していた二重タイトル表記を解消して作業領域の垂直方向の視認性を向上させる。

### Acceptance Criteria

- AC-001: Given 各画面（Overview, Sessions, Jobs, Memory, Recall graph, Activity, Daily）を表示した際 When 画面上部を確認するとき Then グローバルトップバーにページタイトルが集約され、ページ内での二重タイトル表示が解消されていること。
- AC-002: Given サイドバーナビゲーションにおいて When ユーザーがリンクにホバーまたは選択遷移するとき Then 精緻な SVG アイコンとスムーズなアクティブ状態（アクセント背景およびカラー）が即座に切り替わること。
- AC-003: Given ナビゲーションおよびコントロールボタンにおいて When クリック（押下）操作を行うとき Then Emil Kowalski のデザインエンジニアリング思想に基づき、キビキビとしたスケール変化（`:active { transform: scale(0.97); }`）による心地よい押下フィードバックが得られること。
