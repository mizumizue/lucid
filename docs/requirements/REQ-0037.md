## Content

### Statement

Sessions、Jobs、Memory、Activity の各一覧テーブルにおいて、行ホバー効果、洗練されたステータスバッジ（Pill）、および ID や本文のワンクリックコピーボタンを配置し、調査・運用の手戻りを削減する。

### Acceptance Criteria

- AC-001: Given 各種一覧テーブル（Sessions、Jobs、Memory、Activity）において When マウスを行上に移動するとき Then 視認性の高い行ホバーハイライトが表示され、現在参照中のレコードが明確に判別できること。
- AC-002: Given 一覧内のセッション ID、記憶 ID、本文プレビューにおいて When コピーボタンをクリックするとき Then クリップボードへの転記が行われ、Sonner による成功トースト通知がトリガーされること。
- AC-003: Given 各ステータスバッジ（active, done, stale, idle, error, faded）において When 表示するとき Then 統一されたカラーパレットとインジケータードットにより一貫した状態判別ができること。
