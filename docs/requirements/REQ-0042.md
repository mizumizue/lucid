## Content

### Statement

Webダッシュボード（`lucid-memories-dashboard`）において、開発者体験と可読性を向上させるため、ダークテーマを基調とした洗練されたモダンUIデザインの刷新、OS連動および明示的なテーマ切替（ダーク/ライト/システム）、Sonnerを活用した統一的で快適なフィードバック通知、グラフや表を含むコンポーネントの視認性改善、ならびにUI全体の日本語表現の自然化・文字化け防止の最適化を提供する。

### Acceptance Criteria

- AC-001: Given 利用者がダッシュボードを開いたとき When 表示テーマの初期状態が判定される Then デフォルトで高品質なダークテーマが適用され、背景・サーフェス・文字色・境界線・グラフ要素が高いコントラストと視認性で描画されること。
- AC-002: Given 利用者がダッシュボードを閲覧しているとき When トップバーのテーマ切替コントロールでダーク/ライト/システム設定を選択する Then ページ全体および Sonner トースト通知のカラーテーマが即座に連動して切り替わり、選択状態がローカルストレージに永続化されること。
- AC-003: Given 利用者が手動リフレッシュ、検索条件のリセット、またはクリップボードコピー等の操作を実行したとき When 操作が受理または完了する Then Sonner による適切なトースト通知（info/success/error）が表示され、実行状態のフィードバックが即座に認知できること。
- AC-004: Given ダッシュボード内の各種一覧（セッション、記憶、イベント、成果物等）および詳細画面を表示するとき When 空状態（EmptyState）、補助説明、テーブルヘッダー、状態ラベルが描画される Then 不自然な機械翻訳調や文字化けのない自然で一貫した日本語UI表現で提供されること。
