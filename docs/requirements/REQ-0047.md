## Content

### Statement

システムは、未分類または未確定の workspace に対し、Agent が workspace の構成や文脈から種別（例: app-dev, infra, notes, research）および必要な根拠を提案し、ユーザー承認後にのみ workspace と種別の binding を確定記録できる。確定前は種別 overlay を注入しない。

### Acceptance Criteria

- AC-001: Given 種別 binding が未確定の workspace When Agent が分類提案を行う Then 提案種別、根拠、確信度（または同等の説明可能な指標）が記録され、状態は pending として扱われること
- AC-002: Given pending 状態の分類提案 When ユーザーが承認する Then workspace と種別の binding が confirmed となり、以降の persona 合成対象に含まれること
- AC-003: Given pending 状態の分類提案 When ユーザーが却下または別種別を指定する Then 提案は確定されず、ユーザー指定または再提案の結果のみが binding 候補として記録されること
- AC-004: Given 種別 binding が未確定の workspace When プロンプト送信前処理が実行される Then global persona のみが注入され、種別 overlay は注入されないこと
