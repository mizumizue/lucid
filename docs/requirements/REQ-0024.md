## Content

### Statement

想起グラフ API において、同一会話かつ同一プロンプトに対する複数の想起イベント（Retrieval）を 1 つの集約想起ノードにまとめ、想起回数および記憶への参照回数を正確に集計・提供する。

### Acceptance Criteria

- AC-001: Given 同一会話かつ同一プロンプトに対する複数の想起リクエストが存在する場合 When 想起グラフ API がノードおよびエッジを構築するとき Then 個別リクエスト単位ではなく会話・プロンプト単位の集約想起ノードが 1 つ生成され、想起回数（retrieval_count）が正しく集計されること。
- AC-002: Given 集約された想起ノードと記憶（Memory / Map）への参照関係が存在する場合 When 想起グラフのエッジを生成するとき Then 集約ノードから記憶へのエッジが正しく接続され、参照回数（count）が集計されること。
