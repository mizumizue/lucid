## Content

### Statement

Activity index 画面（`ActivityPage`）において、ヘッダー（`ViewIntro`）内に未整形なインライン配置で混在していた期間フィルター（From / To）を、他の画面（`SessionsPage`、`JobsPage`）と統一された独立フィルターパネル（`filter-panel` / `filter-row`）構造に再配置し、デザイン崩れを解消して直感的で整然としたレイアウトを提供する。

### Acceptance Criteria

- AC-001: Given Activity index 画面を表示するとき When 画面上部を確認するとき Then `ViewIntro` には検索入力のみが配置され、期間指定入力（From / To）は下部の独立したフィルターパネル（`.filter-panel` 内の `.filter-row`）として整列描画されること。
- AC-002: Given Activity index の期間フィルターにおいて When 日付入力欄を確認するとき Then システム標準の入力フィールドスタイル（枠線、角丸、背景色、パディング、フォーカス時のアクセント枠）が適用され、ラベルと入力が整然と縦並びグリッドで配置されること。
- AC-003: Given 期間フィルターに開始日（From）または終了日（To）を指定するとき When ユーザーが値を変更するとき Then イベント一覧および成果物一覧の双方に対して即座に絞り込みパラメータが反映されること。
