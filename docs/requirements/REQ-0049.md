## Content

### Statement

システムは、一度 confirmed された workspace の種別 binding および workspace 固有 overlay を、ユーザー操作により後から変更（override）でき、変更履歴または変更時刻を追跡できる。

### Acceptance Criteria

- AC-001: Given confirmed な種別 binding When ユーザーが別種別へ override する Then 新しい binding が有効となり、次回以降の persona 合成に反映されること
- AC-002: Given workspace 固有 overlay When ユーザーが内容を追加・更新・削除する Then 変更が永続化され、次回以降の persona 合成に反映されること
- AC-003: Given override 操作 When 変更が記録される Then いつ誰（またはどの操作源）が変更したかを後から確認できること
- AC-004: Given override 後の workspace When プロンプト送信前処理が実行される Then override 後の binding と overlay のみが合成対象として使用されること
