## Content

### Statement

Overview や Memory、Recall graph で利用されるサマリーメトリクスカードおよびチャート描画要素に対し、モダンなタイポグラフィ（等幅数字、洗練されたフォント階層）、マイクロインタラクション、およびノイズの少ない上品なカードレイアウトを適用する。

### Acceptance Criteria

- AC-001: Given サマリーメトリクスカードを表示する際 When 数値を確認するとき Then `font-variant-numeric: tabular-nums` を適用した見やすい等幅フォントと洗練されたステータスドット・ラベルで整然と描画されること。
- AC-002: Given メトリクスカードにマウスをホバーするとき When ユーザーが視線を移すとき Then 微細なボーダー色の変化とシャドウのリフト効果により、自然なインタラクティブ性が提供されること。
- AC-003: Given Overview の日次アクティビティチャートおよびモデル利用状況において When 棒グラフやバーにカーソルを合わせるとき Then キビキビとしたトランジションで値の強調が行われること。
