## Content

### Statement

リポジトリ構成としてペルソナディレクトリ（`persona/`）を維持しつつ、新規環境における初期セットアップ実行時にはデフォルトのペルソナルールおよび設定ファイルを空（ルールなし）で生成する。

### Acceptance Criteria

- AC-001: Given ペルソナ設定ファイルが存在しないクリーンな環境 When セットアップスクリプトの `ensure_persona` を実行する Then `persona/user-rules.json` および `persona/persona.json` が空のルール（`rules: []`, `sections: []`）として正常に初期化され、`persona validate` が成功（exit code 0 / ok: true）すること。
- AC-002: Given すでに `persona/user-rules.json` や `persona/persona.json` が存在する環境 When セットアップスクリプトを実行する Then 既存のルールおよび設定ファイルが上書きされずそのまま保護（preserved）されること。
- AC-003: Given リポジトリ内の `persona/` ディレクトリ When Git 管理およびファイル除外設定を評価する Then `persona/.gitkeep` によってディレクトリ自体はリポジトリに維持され、ユーザー固有の JSON 設定ファイル（`persona/*.json`）のみが Git 管理から除外されること。
