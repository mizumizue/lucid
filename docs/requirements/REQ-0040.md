## Content

### Statement

正本ダッシュボード（`lucid-memories-dashboard`）において、従来静的HTMLファイル（`guide.html`）への外部リンクとして提供されていた用語および機能ガイドを、React / TypeScript による SPA ネイティブな画面コンポーネント（`/guide`）として完全に取り込み、画面遷移の分断なくダッシュボード内で直接閲覧・操作可能とする。

### Acceptance Criteria

- AC-001: Given 利用者がダッシュボードのサイドバー、トップバー、フッター、またはモーダル内のガイド導線をクリックするとき When 画面遷移が行われる Then 外部HTMLファイルへのページ移動や別タブ展開を伴わず、React Router によるクライアントサイドナビゲーションとして `/guide` ビューが表示されること。
- AC-002: Given 利用者が `/guide` 画面を表示しているとき When 用語検索ボックスにキーワードを入力する Then 該当する用語カードのみがインクリメンタルにリアルタイムフィルタリングされ、結果件数が反映されること。
- AC-003: Given 利用者が `/guide` 画面の FAQ セクションを表示しているとき When 質問項目をクリックする Then アコーディオンが開閉し、対応する回答テキストがスムーズにトグル表示されること。
- AC-004: Given 静的配信サーバーにおいてフロントエンド成果物（`index.html`）が配置されているとき When 利用者が `/guide` へ直接アクセスまたは再読み込み（リロード）を行う Then SPA の `index.html` が返却され、React Router によりガイド画面が正常に初期描画されること。
