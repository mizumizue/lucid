## Content

### Statement

セッション詳細（SessionDetailPage）およびアーティファクト詳細（ArtifactDetailPage）において、メタデータとプロンプト・出力コードブロックの視覚的区切りを明確化し、全文コピー機能およびトースト通知を提供する。

### Acceptance Criteria

- AC-001: Given セッションまたはアーティファクト詳細画面において When プロンプト、出力、本文、またはメタデータ JSON を確認するとき Then 読みやすいシンタックス背景と余白を持つ整形コードブロックで表示されること。
- AC-002: Given 詳細画面の各テキスト・コードセクションにおいて When コピーボタンをクリックするとき Then 選択内容全体がクリップボードにコピーされ、対象名を明示したトーストが表示されること。
- AC-003: Given 直前の画面へ戻る操作において When ユーザーがナビゲーションするとき Then 明確な戻るリンクまたはパンくずリストが機能すること。
