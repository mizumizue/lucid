## Content

### Context

ADR-0007 により外部リポジトリから運用ダッシュボード（React + TypeScript + Vite）がリポジトリ内に内包された際、フロントエンド資産一式がリポジトリルートの `frontend/` に暫定配置された。

しかし、以下の課題が生じていた。
1. **リポジトリルートの散乱**: リポジトリルートに `frontend/` が露出することで、Python パッケージ基幹リポジトリとしての責務境界が曖昧になり、ルート直下の見通しを損ねていた。
2. **組み込みUI（`src/lucid_memories/web/`）との二重性・分断**: 元来本リポジトリに存在した想起グラフ可視化・用語ガイド（`dashboard.html`, `guide.html`）と、新規に取り込んだ運用コンソールが別系統として扱われ、ダッシュボードサーバー起動時（`dashboard.py`）の二重ハンドラー構造や、React アプリ側からの用語解説・ガイドへのアクセス欠落といった分断が存在していた。

### Decision

フロントエンド資産一式をリポジトリルートから `src/lucid_memories/web/frontend/` へ完全移設し、lucid-memories の組み込み Web サブシステム（`lucid_memories.web`）と一体化・統合する。

1. **配置パスの移設**:
   - `frontend/` を `src/lucid_memories/web/frontend/` へ移動し、リポジトリルートをクリーンに保つ。
   - ビルド成果物の出力先を `src/lucid_memories/web/dist/`（および `src/lucid_memories/web/frontend/dist/`）とし、Python パッケージ同梱アセットとして自然に扱える構造とする。
2. **組み込みUIとしての機能統合**:
   - 旧組み込みUI（`dashboard.html`）に備わっていた「用語早見表（クイック用語解説）」および「用語・使い方ガイド（`/guide`）」への導線を、React コンソール（`AppShell`、`RecallGraphPage` 等）に完全統合する。
   - `lucid-memories dashboard` コマンドで起動されるサーバーが、標準で統合運用コンソールを配信し、同一サーバー内で `/guide` への案内も含めた一貫した観測性を提供する。
3. **設定・パス探索の統合**:
   - `Settings` の `default_frontend_dist()` において、`src/lucid_memories/web/dist` および `src/lucid_memories/web/frontend/dist` を最優先候補として解決する。
   - ドキュメント（`TC-0009`、`README.md` 等）および `.gitignore` の参照パスを更新する。

### Consequences

- リポジトリルートから `frontend/` が排除され、`src/` 配下の Python パッケージ `lucid_memories.web` 内にバックエンド・フロントエンド・静的アセットが集約される。
- 従来の組み込みUIの良さ（概念のわかりやすい用語解説・完全ガイド）がモダンな運用コンソールに統合され、ユーザー体験が大幅に向上する。
- パッケージ配布時や `lucid-memories dashboard` 実行時に、別ディレクトリへの依存なく単一パッケージ内で完結してリッチなダッシュボードが稼働する。
