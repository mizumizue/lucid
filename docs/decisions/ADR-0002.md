## Content

### Context

開発中のソースコード、決定事項、およびエージェントの作業コンテキストには機密情報や社外秘が含まれることが多く、外部のサードパーティクラウドストレージや外部APIへ無断で送信されることはセキュリティ上の重大なリスクとなる。

### Decision

すべてのデータ永続化（SQLite, CAS Blobs, Ladybug DB）および推論基盤（Ollama nomic-embed-text）を開発者のローカルマシン上で完全に完結させるアーキテクチャを採用する。外部クラウドへのデータ送信を行わない。

### Consequences

- ネットワーク切断環境下でも動作可能であり、機密情報の漏洩リスクをゼロに抑えることができる。
- ローカルマシンへの Ollama や Python 実行環境のセットアップが必要となり、利用者のマシンリソース（CPU/メモリ）を一定程度消費する。
