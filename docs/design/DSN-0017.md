## Content

### Decision

Emil Kowalski のデザインエンジニアリング思想（マイクロインタラクション、キビキビしたトランジション、適切なイージング、無駄なアニメーションの排除）および Sonner のトースト通知機構をダッシュボード全域（Overview、Sessions、Jobs、Memory、Recall graph、Activity、Daily、Detail）に導入し、CSS 設計およびコンポーネント構造を刷新する。

### Structure

1. **デザインシステムトークン（CSS Variables）**:
   - `--ease-out`: `cubic-bezier(0.23, 1, 0.32, 1)`（UI 操作の標準）
   - `--ease-in-out`: `cubic-bezier(0.77, 0, 0.175, 1)`
   - `--ink`: `#0f172a`（深みのあるスレートインク）
   - `--paper`: `#f8fafc`（クリーンなオフホワイト背景）
   - `--card`: `#ffffff`（純白カード）
   - `--line`: `#e2e8f0`（繊細で均一な境界線）
   - `--indigo`: `#6366f1` / `--indigo-soft`: `#eef2ff`
   - `--mint`: `#10b981` / `--mint-soft`: `#ecfdf5`
   - `--coral`: `#f43f5e` / `--coral-soft`: `#fff1f2`
   - `--yellow`: `#f59e0b` / `--yellow-soft`: `#fef3c7`
   - `--shadow-sm`, `--shadow-md`, `--shadow-lg`: モダンな多層ソフトシャドウ
2. **ボタン & 入力コンポーネント**:
   - `button:active`: `transform: scale(0.97)` を一律適用
   - `button`: `transition: transform 160ms var(--ease-out), background-color 160ms var(--ease-out), border-color 160ms var(--ease-out)`
   - 入力フィールドフォーカス時のリングハイライト（`box-shadow: 0 0 0 3px rgba(99, 102, 241, 0.15)`）
3. **メトリクスカード**:
   - 煩雑な背景装飾円を廃止し、上質な左アクセントバーまたはバッジカラー、および数値の `font-variant-numeric: tabular-nums` で可読性を最大化。
4. **トースト統合レイヤー**:
   - `sonner/dist/styles.css` を明示インポートし、ダッシュボードのパレットと自然に調和するスタイリングを保証。

### Data Flow

1. ユーザーが操作（コピー、更新、リセット、タブ選択）を実施。
2. イベントハンドラー内で処理を実行。
3. 処理結果（成功・失敗・状態遷移）に応じて `toast.success()`, `toast.info()`, `toast.error()` を即時発火。
4. `<Toaster />` が右下にリッチカラーのトーストをキューイング・スタック描画。

### Trade-offs

- **CSS-in-JS や Tailwind の非採用**:
  - 既存の純粋な CSS 設計（`styles.css`）のシンプルさと Vite ビルドの俊敏性を維持するため、Tailwind への全面書き換えではなく、洗練された CSS トークンとコンポーネントクラスのリファクタリングを選択した。これによりビルド設定の肥大化を防ぎ、保守性を高めている。
