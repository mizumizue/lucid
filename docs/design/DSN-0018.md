## Content

### Decision

`ActivityPage.tsx` において、`ViewIntro` 内にインライン配置されていた無効な CSS クラス群（`.view-controls`, `.date-controls`）を撤廃し、`SessionsPage` および `JobsPage` と完全に同一の `<Panel className="filter-panel"><div className="filter-row">...</div></Panel>` 構造へと移行する。

### Structure

1. **コンポーネント階層**:
   ```tsx
   <div className="view">
     <ViewIntro
       description="..."
       kicker="TRACEABILITY INDEX"
       title="Activity index"
     >
       <SearchInput
         label="アクティビティを検索"
         onChange={(value) => setValue("q", value)}
         placeholder="会話・ファイル・出力を検索"
         value={q}
       />
     </ViewIntro>
     <Panel className="filter-panel">
       <div className="filter-row">
         <label>
           From
           <input onChange={(event) => setValue("from", event.target.value)} type="date" value={from} />
         </label>
         <label>
           To
           <input onChange={(event) => setValue("to", event.target.value)} type="date" value={to} />
         </label>
       </div>
     </Panel>
     <div className="index-grid">
       {/* Events & Artifacts Panels */}
     </div>
   </div>
   ```
2. **CSS スタイル適用**:
   - `.filter-panel`: カード型コンテナ（白背景、境界線、角丸 12px、シャドウ、下部余白 20px）。
   - `.filter-row`: `display: flex; flex-wrap: wrap; align-items: flex-end; gap: 14px;`。
   - `.filter-row label`: `display: grid; gap: 5px; color: var(--muted); font-size: 11px; font-weight: 500;`。
   - `.filter-row input`: `min-width: 130px; padding: 7px 10px; border: 1px solid var(--line); border-radius: 7px;`。

### Data Flow

1. ユーザーが日付入力フィールド（From / To）の値を変更する。
2. `setValue` フックにより URL クエリパラメータ（`from`, `to`）が更新される。
3. `useResource` フックが変更を検知し、`api.events(...)` および `api.artifacts(...)` を並行再取得する。
4. 取得された最新のイベントおよび成果物一覧が再描画される。

### Trade-offs

- **ヘッダー内インライン配置 vs 独立パネル配置**:
  - ヘッダー内に詰め込むと垂直方向の消費スペースは抑えられるが、日付入力欄が押し込まれてタイトルや説明文と重なり、レスポンシブ崩れやラベルと入力欄のアンバランスが発生する。
  - 独立した `filter-panel` に分離することで、垂直方向にわずかな余白を要するものの、ダッシュボード全体（Sessions, Jobs, Memory）との一貫性が保たれ、視認性と操作性が大幅に向上する。
