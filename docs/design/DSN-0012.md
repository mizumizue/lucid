## Content

### Decision

ユーザー方針の正本をローカルの JSON ファイル群（`persona.json`, `user-rules.json`）として保持し、フック実行時に高速キャッシュ・読み込みを行いつつ、会話履歴からのルール抽出・改定履歴管理を独立したテーブルで追跡する自己学習パイプラインを構築する。

### Structure

- `core.persona`: ペルソナのロード、優先度順結合、フォーマット生成、および候補抽出処理を担当。
- `persona/` ディレクトリ: 正本ファイル群（`persona.json`, `user-rules.json`）。
- `persona_candidates` テーブル: 抽出された新しいルール候補を保持。
- `persona_revisions` テーブル: ペルソナ設定の適用履歴・差分ログを保持。

### Data Flow

1. プロンプト送信時、`core.persona.build_persona_prompt` が正本ファイルを読み込み、トークン予算内でテキストを合成する。
2. 対話終了時、`hook.py` がユーザーの要求・指示内容を解析し、定型的なルール要求を検出する。
3. 検出されたパターンは `persona_candidates` に書き込まれる。
4. 利用者またはエージェントが承認した場合、正本ファイルが改定され、`persona_revisions` にバージョン履歴が記録される。

### Trade-offs

- ユーザー固有のルールが Cursor のワークスペース設定に依存せずマシン全体で一貫して適用され、かつ自然な対話を通じて進化できる。
- 自動反映ではなく承認ステップを挟むため、誤った指示や一時的な例外指示がグローバルペルソナに混入する事故を防ぐ。
