## Content

### Decision

`scripts/setup.py` の `ensure_directories` 関数から `blobs` および `logs` のディレクトリ生成処理を完全に撤廃する。さらに、過去の実行等で既に生成されてしまっている空の `blobs` および `logs` ディレクトリが存在する場合は、`ensure_directories` の実行時に自動で除去するクリーンアップ機構を導入する。

### Structure

- `ensure_directories(repo_root: Path) -> None`:
  - 必須ディレクトリ（`~/.cursor/hooks`, `~/.cursor/skills`, `repo_root / ".db"`, `repo_root / "persona"`）を `mkdir(parents=True, exist_ok=True)` で確保する。
  - `clean_legacy_directories(repo_root: Path) -> None`:
    - `repo_root / "blobs"` および `repo_root / "logs"` を走査し、ディレクトリが存在しかつ配下にファイルが存在しない（空である）場合に `rmdir` により安全に削除する。ファイルが含まれている場合は削除せず警告ログを記録する。

### Data Flow

1. セットアップスクリプト起動時に `ensure_directories(repo_root)` が呼ばれる。
2. 必須ディレクトリのみが作成される。
3. レガシーディレクトリ検査が行われ、空の `blobs` / `logs` が存在する場合は安全に削除される。
4. 処理完了ログが出力される。

### Trade-offs

- 自動削除を行うことでワークスペースを常に清潔に保てる。
- 万が一手動で何かファイルを置いていた場合に備えて空ディレクトリのみの削除に限定することで、データ消失リスクを回避する。
