## Content

### Decision

ローカルでの記憶・グラフ可視化を提供するため、FastAPI / Starlette による軽量な HTTP サーバ（既定ポート 8765）を立ち上げ、単一HTMLファイル（ダッシュボード・ガイド）とREST APIエンドポイントを配信する構成とする。

### Structure

- `web.dashboard`: FastAPI アプリケーションインスタンス、ポート管理、バックグラウンド起動ロジック。
- `web/dashboard.html`: vis-network 等のグラフ可視化ライブラリを組み込んだフロントエンド画面。
- `web/guide.html`: 用語定義や活性度・減衰モデルの解説画面。
- `/api/graph`, `/api/memories` エンドポイント: ナレッジグラフと記憶一覧を JSON 形式で配信。

### Data Flow

1. 利用者が CLI またはツールから `dashboard` コマンドを実行し、ローカル HTTP サーバを起動する。
2. ブラウザが `http://127.0.0.1:8765/` にアクセスすると、静的 HTML が返却される。
3. HTML 内の JavaScript が `/api/graph` および `/api/memories` を非同期フェッチする。
4. `core.api` を経由して SQLite / Ladybug から取得されたノード・エッジ・温度データが描画される。

### Trade-offs

- 外部CDNやクラウドへの依存なしに、ブラウザだけで直感的にナレッジグラフと記憶状態を俯瞰できる。
- サーバ常駐のためのローカルポート競合やプロセスマネジメントの考慮が必要となる。
