## Content

### Decision

~~ナレッジグラフ基盤として、プライマリに Ladybug DB（組み込み Cypher グラフエンジン）を採用しつつ、ライブラリ未導入環境や障害時には SQLite 内のオントロジー表へ透過的にフォールバックするハイブリッド構造とする。~~

**本設計は ADR-0011 により superseded。** フォールバックは実装されず、Ladybug は Map エッジ操作の必須依存。ノード索引は SQLite `ontology_nodes` が正本。

### Structure

- `runtime.ladybug_runtime`: Ladybug DB 接続。Cypher（MATCH, MERGE）でエッジを管理する必須アダプタ。
- `storage.db`: `ontology_nodes` および FTS。ノード解決とメタデータの正本。
- `core.graph`: ノードは SQLite、エッジは Ladybug に二重書き込みするファサード。

### Data Flow

1. `link` / `recall` 等が `core.graph` に届く。
2. ノード解決・作成は SQLite `ontology_nodes` で行う。
3. エッジの作成・探索・状態更新は Ladybug Cypher で行う。
4. Ladybug 未接続時は Map 操作は失敗または空結果（フォールバックなし）。

### Trade-offs

- Cypher による多段グラフ探索を維持できる。
- SQLite エッジフォールバックを実装しないため保守コストは抑えられる。
- Ladybug セットアップ（Windows OpenSSL シム含む）が必須となる。
