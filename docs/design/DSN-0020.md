## Content

### Decision

機密情報・個人情報の漏洩防止を単一のメカニズム（`.gitignore` のみ、または Git フックのみ）に依存させず、(1) 静的追跡除外（`.gitignore`）、(2) Git ネイティブフック（`hooks/pre-commit`）、(3) AI エージェント実行時ガード（`core.gate.shell_permission`）の多層防御（Defense-in-Depth）構造として設計・実装する。

### Structure

1. **静的ファイル追跡除外層 (`.gitignore`)**:
   - `persona/*.json`、`.env*`、秘密鍵、トークン等のパターンを明示。
2. **Git コミット時検証層 (`hooks/pre-commit`, `hooks/pre-commit.cmd`, `core.privacy_gate`)**:
   - Git コミット実行時にステージング領域（`git diff --cached`）のファイルパスおよび差分内容をスキャンし、コミットを遮断。
3. **エージェント実行時インターセプト層 (`core.gate`, `entrypoints.hook`)**:
   - AI エージェントがシェルで `git commit` や機密ファイルの `git add` を実行しようとした際、`shell_permission` が介入して `ask` 状態とし、ユーザー確認を必須化。

### Data Flow

```text
[User / Agent Commit Action]
            │
            ▼
┌───────────────────────────────┐
│ Cursor Hook: gate.py          │ ── (Sensitive detected) ──> [Permission: ASK] (Intercepted)
└───────────────────────────────┘
            │ (Pass)
            ▼
┌───────────────────────────────┐
│ Git Engine: git commit        │
└───────────────────────────────┘
            │
            ▼
┌───────────────────────────────┐
│ Pre-commit Hook               │ ── (Violation found)    ──> [Exit Code 1] (Commit Aborted)
└───────────────────────────────┘
            │ (Pass)
            ▼
    [Commit Created]
```

### Trade-offs

- **利便性と安全性のバランス**: 開発者がローカル専用リポジトリで作業する場合や `.env.example` のような安全な設定テンプレートをコミットする場合に誤検知で作業が停滞しないよう、`is_local_only_repo` による自動スキップ機能および `SAFE_PATH_ALLOWLIST` を設けている。
