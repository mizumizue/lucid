## Content

### Decision

従来 `src/lucid_memories/web/guide.html` にハードコードされていた全文書コンテンツ・スタイル・対話スクリプトを、TypeScript / React コンポーネント `src/lucid_memories/web/frontend/src/views/GuidePage.tsx` へ完全移植する。同時に、グローバルナビゲーションおよび各ビュー内のガイド導線を React Router の内部リンク（`<Link to="/guide">`）に統一し、バックエンドの静的配信処理において SPA を最優先するルーティングへと改修する。

### Structure

1. **データ定義とコンポーネント分離**:
   - `GLOSSARY_ITEMS`: 用語名、別名、タグ、バッジ分類、要約、詳細、具体例を保持する不変データ構造。
   - `FAQ_ITEMS`: 質問と回答を保持する不変データ構造。
   - `FLOW_STEPS`: 会話と記憶のライフサイクルステップ定義。
   - `GuidePage`: 状態管理（検索キーワード `searchTerm`、開閉 FAQ インデックス集合 `openFaqIndexes`）と各セクションのレンダリング。
2. **ルーティング統合**:
   - `App.tsx`: `<Route element={<GuidePage />} path="guide" />` を登録。
   - `components.tsx`:
     - サイドバーの `navigation` 配列に `{ to: "/guide", label: "Guide", icon: <GuideIcon /> }` を追加。
     - サイドバー・トップバー・フッター・モーダル内の `<a>` リンクを `<Link to="/guide">` または `<NavLink>` に置き換え。
3. **バックエンド配信境界（`http_api.py`）**:
   - `settings.frontend_dist` に `index.html` が存在する場合、`/guide` は SPA の `index.html` を返却し、React Router によるクライアント側ルーティングを有効化する。
   - SPA ビルドが存在しない環境またはスタンドアロン配信時のみ、後方互換として従来の `guide.html` を返却する。

### Data Flow

```text
[Sidebar / Topbar / Modal / RecallGraph] ── (Link to="/guide") ──> [React Router]
                                                                        │
                                                                 [GuidePage.tsx]
                                                                        │
                   ┌────────────────────────────┬───────────────────────┴───────────────────────┐
                   ▼                            ▼                                               ▼
         [用語リアルタイム検索]         [目次スクロール]                              [FAQ 開閉アコーディオン]
    (searchTerm ──> filter(items))  (href="#...")                             (toggle index in openFaqIndexes)
```

### Trade-offs

- **SPA 内包によるバンドルサイズ**: 静的ガイドコンテンツを JavaScript バンドルに内包することでアセットサイズが約数十 KB 増加するが、ネットワーク遅延のない即時画面遷移と、ダッシュボード全体の統一されたダークテーマ・フォント・UI 体験が得られるメリットが大幅に上回る。
- **後方互換性**: ビルド前や軽量モード向けに `guide.html` も残存させるが、正本コンソールが利用可能な環境では完全な SPA ルーティングが優先される。
