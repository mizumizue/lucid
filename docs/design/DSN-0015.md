## Content

### Decision

React SPA を正本のダッシュボードとして使用し、Sonner の Toaster、インタラクティブなグラフのハイライト、インクリメンタル検索、コピー機能、およびメトリクスカードをコンポーネントとして提供する。

### Structure

1. **Toast Manager (`Toaster`)**:
   - `App.tsx` に Sonner の `<Toaster>` を配置。
   - 各ビューは `toast.success`、`toast.error`、`toast.info` を利用する。
   - 機能: タイトル・説明（description）の表示、richColors（色分け・アクセント）、閉じるボタン、スタック表示。
2. **Metrics Summary Component**:
   - `#stats` 領域を 4 つのグリッドカード（総想起ログ、会話セッション数、想起ノード数、参照知識ノード数）へ拡張。
3. **Interactive Graph Engine**:
   - グラフ描画時に各ノードとエッジに隣接関係（`adjacencyMap`）を保持。
   - ノード選択時に接続エッジに `.highlighted`、関連ノードに `.highlighted`、それ以外の非接続要素に `.dimmed` クラスを付与。
4. **Search & Filter Controller**:
   - `#keyword-search` の入力イベントで debounce を行い、テキスト（タイトル、プロンプト、本文）を含むノードとその関連要素を動的抽出。
   - `#reset-filters` で全入力値を初期化し即座に全体描画を復元。
5. **Clipboard & Action Utilities**:
   - `navigator.clipboard.writeText()` を利用した安全なコピー処理とトースト通知の連動。

### Data Flow

1. ページ読み込み時または更新操作時、`api.recallGraph()` が `/api/v1/recall-graph` を呼び出し。
2. 取得成功時、`state.graph` を更新し、`toast.success("グラフを更新しました", { description: "XX件の想起ログを取得しました" })` を発行。
3. ユーザーが検索入力欄にキーワードを入力すると、`filterGraph()` が `nodes` をフィルタリングして `render()` を再実行。
4. ノードがクリックされると `selectNode()` が走り、詳細パネル描画と同時に SVG 要素のクラス切り替え（`.dimmed` / `.highlighted`）を実行。
5. コピーボタン押下時、テキストをクリップボードに書き込み、`toast.success("コピーしました")` を発行。

### Trade-offs

- **React SPA vs 単一HTML**: React と npm 依存をビルド時に束ねることで、実行時の CDN 依存を避けつつ、ルーティングと画面間の UI を統一する。
- **ビルド成果物の配信**: バックエンドは `frontend/dist` の成果物だけを配信し、古い HTML フォールバックを持たないことで配信経路を一つに保つ。
