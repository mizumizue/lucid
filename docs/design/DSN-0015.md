## Content

### Decision

ダッシュボードの単一HTML構成（`dashboard.html`）を維持しつつ、Sonnerの設計思想を取り入れた軽量・堅牢なトーストマネージャーをフロントエンド内に組み込み、SVGグラフのインタラクティブなハイライト機構、インクリメンタル検索、コピー機能、およびメトリクスカードを追加する。

### Structure

1. **Toast Manager (`toast`)**:
   - DOMルートに `<div id="sonner-toaster" role="region" aria-label="Notifications">` を配置。
   - API: `toast(title, opts)`, `toast.success(title, opts)`, `toast.error(title, opts)`, `toast.info(title, opts)`。
   - 機能: タイトル・説明（description）の表示、richColors（色分け・アクセント）、閉じるボタン、一定時間での自動退去（デフォルト3500ms）、ホバー時のタイマー一時停止、スタック表示。
2. **Metrics Summary Component**:
   - `#stats` 領域を 4 つのグリッドカード（総想起ログ、会話セッション数、想起ノード数、参照知識ノード数）へ拡張。
3. **Interactive Graph Engine**:
   - グラフ描画時に各ノードとエッジに隣接関係（`adjacencyMap`）を保持。
   - ノード選択時に接続エッジに `.highlighted`、関連ノードに `.highlighted`、それ以外の非接続要素に `.dimmed` クラスを付与。
4. **Search & Filter Controller**:
   - `#keyword-search` の入力イベントで debounce を行い、テキスト（タイトル、プロンプト、本文）を含むノードとその関連要素を動的抽出。
   - `#reset-filters` で全入力値を初期化し即座に全体描画を復元。
5. **Clipboard & Action Utilities**:
   - `navigator.clipboard.writeText()` を利用した安全なコピー処理とトースト通知の連動。

### Data Flow

1. ページ読み込み時または更新操作時、`loadGraph()` が `/api/graph` を呼び出し。
2. 取得成功時、`state.graph` を更新し、`toast.success("グラフを更新しました", { description: "XX件の想起ログを取得しました" })` を発行。
3. ユーザーが検索入力欄にキーワードを入力すると、`filterGraph()` が `nodes` をフィルタリングして `render()` を再実行。
4. ノードがクリックされると `selectNode()` が走り、詳細パネル描画と同時に SVG 要素のクラス切り替え（`.dimmed` / `.highlighted`）を実行。
5. コピーボタン押下時、テキストをクリップボードに書き込み、`toast.success("コピーしました")` を発行。

### Trade-offs

- **React導入 vs Vanilla JS組込**: Reactや外部npm版SonnerをCDNから読み込む案はオフライン環境や閉鎖ネットワークで動作不能になるリスクがある。本設計ではSonnerの視覚的・操作的体験（API、スタッキング、richColors、アニメーション）を完全に再現した自己完結型トースト機構を組み込み、移植性と信頼性を最大化する。
- **フル再描画 vs DOM差分更新**: 単純なSVG再描画はデータ量が数百件規模であるためパフォーマンス上十分高速であり、複雑なVDOMを用いずにシンプルさを保つ。
